About the project

A closer look.

OrthoLens AI is a computer-vision project focused on bone X-ray analysis. The idea is simple: use machine learning to help organize image analysis outputs in a way that is easier to explore, inspect, and understand.
01 — What is OrthoLens?

Built around the image, not the hype.

OrthoLens AI brings together a web interface, a Python backend, and a YOLO-based computer-vision pipeline for bone X-ray analysis.

The current implementation focuses on fracture-related detection. A user can upload an X-ray, send it through the model, and inspect the resulting annotated image and available visual explanation.

The project is designed to make experimentation with medical imaging AI more approachable while keeping the model output and its limitations visible to the user.

02 — Our approach

Three things guide the project.

01

Clarity

Present model outputs in a way that is understandable instead of hiding the process behind a single result.

02

Experimentation

Treat datasets, models, inference settings, and explainability methods as things that can be tested and improved.

03

Responsibility

Keep experimental model predictions distinct from professional clinical interpretation and diagnosis.

03 — How it came together

From model to interface.

01

Computer vision

The project uses an object-detection approach based on Ultralytics YOLO to process bone X-ray images and identify regions associated with the model's trained labels.

02

Backend integration

FastAPI connects the image-upload workflow with model inference, generated result files, health checks, and the browser interface.

03

Visual interpretation

Annotated outputs and explanation views are included so that users can inspect where the model responded rather than only receiving a text prediction.

04

Continuous improvement

The project can evolve through better datasets, improved model evaluation, more robust explanation methods, and cleaner user-facing workflows.

04 — Current scope

What exists today.

The current release is centered on fracture-related X-ray analysis. Other capabilities are considered future extensions rather than existing features.

01

Fracture detection

YOLO-based inference using the currently available trained detector.

02

Annotated results

Generated result images allow users to inspect detected regions directly on the uploaded X-ray.

03

Visual explanation

Explanation outputs provide an additional way to inspect the model's response.

04

Future research

Skeletal-age estimation and biological-sex classification may be explored later using dedicated datasets and independently evaluated models.

OrthoLens AI is intended for research and educational exploration. Its model outputs should not be treated as medical diagnoses or as a substitute for professional clinical interpretation.
