Project overview

Inside OrthoLens AI.

OrthoLens AI is a computer-vision project built to explore bone X-ray analysis through object detection, visual overlays, and a simple browser-based interface. The project connects a trained YOLO model with a FastAPI backend and a lightweight frontend.

The idea

A small project built around one clear workflow.

Upload an X-ray, send it through the backend, run the trained detector, and make the returned information easier to inspect through the interface.

What OrthoLens AI explores

The project combines machine learning and web development to demonstrate an end-to-end computer-vision application. The focus is on connecting a trained detection model with an accessible interface rather than presenting the system as a clinical diagnostic product.

Architecture: frontend + FastAPI + YOLO
Input: JPG / PNG X-ray images
Output: detected regions and confidence
Use: research, learning, and demonstration

Current scope

What the prototype does — and doesn't.

Being clear about the project's boundaries is part of making a machine-learning demo useful and honest.

Dataset-dependent behavior

Performance can vary when an input image differs from the data distribution represented during training.

Not a clinical tool

The current project is intended for experimentation, education, and demonstration rather than medical diagnosis.

Prototype explanation

The current visual explanation is a heatmap-style overlay generated from detected regions rather than a verified gradient-based Grad-CAM implementation.

Future development

Where the project can grow.
